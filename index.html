Mission Sequence

Each run starts from a randomized position and heading.

  1. Camera reads the scroll colour and picks the stand-off: red 400 mm, blue 600 mm.
  2. IMU and front ultrasonic distance sensor compute heading relative to the scroll face.
  3. The robot rotates in place until it squarely faces the target scroll.
  4. Omni wheels allow simultaneous lateral and forward translation to close on the target.
  5. Fine micro-corrections hold position and heading steady before signalling ready.

01 // Engineering Problem Statement & Design Objectives

Autonomous Target Identification & Precision Stand-Off Locking

TOLERANCE SPEC: ±2.0 MM AXIAL · ±0.5° HEADING ALIGNMENT

The Arena Challenge

In autonomous robotic inspection trials, a mobile platform is deployed at an arbitrary starting coordinate and random yaw orientation inside the arena. Mounted on the far datum wall is a vertically suspended target scroll encoded by colour (Crimson Red or Cobalt Blue).

Conventional differential-drive robots suffer from non-holonomic constraints—requiring multi-point turns that induce wheel slip, cumulative odometry drift, and camera field-of-view loss. Team AOSAR engineered the Tri-Tier Scanner Robot around a 120° 3-wheel Kiwi-Drive holonomic chassis, decoupling rotational alignment ($\omega$) from planar translation ($V_x, V_z$).

Condition A // Red Scroll 400 mm

Close-range optical inspection profile. Ultrasonic array locks the front bumper datum at exactly 400.0 mm from the scroll plane.

Condition B // Blue Scroll 600 mm

Wide-field macro framing profile. Closed-loop PID controller halts forward translation at 600.0 mm stand-off distance.

03 // Holonomic Locomotion & Mathematical Model

120° Kiwi-Drive Inverse Kinematics

WHEEL ANGLES: θ₁ = 90° (FRONT) · θ₂ = 210° (REAR-L) · θ₃ = 330° (REAR-R)

Inverse Kinematics Transformation

Each Ø100 mm omni wheel ($r = 50\text{ mm}$) is mounted at radial distance $R = 330\text{ mm}$ from the robot's center of mass at angles $\theta_i \in \{90^\circ, 210^\circ, 330^\circ\}$. Passive peripheral rollers allow free slip perpendicular to each wheel's drive plane.

To command a desired robot body velocity vector $\mathbf{V}_b = [V_x, V_z, \omega]^T$ in the arena frame, the ESP32 computes individual wheel angular velocities $\omega_i$ (rad/s) at 100 Hz via the exact inverse Jacobian matrix:

// KIWI-DRIVE INVERSE JACOBIAN MATRIX (r = 0.05m, R = 0.33m)
┌ ω₁ ┐     1   ┌ -sin(90°)   cos(90°)   -R ┐ ┌ Vx ┐
│ ω₂ │ = ───── │ -sin(210°)  cos(210°)  -R │ │ Vz │
└ ω₃ ┘     r   └ -sin(330°)  cos(330°)  -R ┘ └ ω  ┘

ω₁ (90° Front)  = ( -1.000·Vx + 0.000·Vz - 0.330·ω ) / 0.050
ω₂ (210° RearL) = ( +0.500·Vx - 0.866·Vz - 0.330·ω ) / 0.050
ω₃ (330° RearR) = ( +0.500·Vx + 0.866·Vz - 0.330·ω ) / 0.050
Pure Forward (+Vz) ω₁ = 0, ω₂ = −ω₃
Pure Strafe (+Vx) ω₂ = ω₃ = −½ω₁
Pure Spin (ω) ω₁ = ω₂ = ω₃

04 // Electrical Bus & Control Topology

Power Distribution & Sensor Fusion Pipeline

DUAL-RAIL ISOLATION: 12.8V TRACTION BUS · 5.0V / 3.3V LOGIC BUS

Power Distribution & Filtering Tree

12V 10Ah LiFePO4

High-current inductive spikes from three 200 RPM brushed DC motors are decoupled from the ESP32 and I2C sensors using a multi-stage capacitor bank (10× 470–1000 µF electrolytic bulk reservoirs + 2× 0.1 µF ceramic bypass discs) and an MP1584 high-frequency buck regulator.

1. Primary Energy Storage 12V 10Ah LiFePO4 Pack → Inline Blade Fuse → Main Toggle Switch
12.8V DC
2. High-Current Traction Bus Screw Terminal Block → 2× Cytron MDD10A Drivers → 3× 200 RPM Motors
Up to 20A
3. Regulated Logic & Sensor Bus MP1584 Buck Converter + 10× 1000µF & 2× 0.1µF Caps → ESP32 & Peripherals
5.0V / 3.3V
4. Signal Level Shifting Network 2 kΩ / 1 MΩ Axial Resistor Dividers on 5V Ultrasonic Echo & Encoder Lines
3.3V Safe GPIO

Autonomous Finite State Machine (FSM)

ESP32 Dual-Core

The onboard software executes a deterministic 5-state control pipeline. Sensor inputs from the mast camera, upper-tier MPU6050 6-axis IMU, front dual HC-SR04 ultrasonic sensors, and 3 quadrature wheel encoders are fused in real time:

S1

STATE_SCAN // HSV Colour Segmentation

Corner mast camera (Y = 578 mm) classifies scroll hue and assigns target stand-off $D_{\text{target}} \in \{400\text{ mm}, 600\text{ mm}\}$.

S2

STATE_ALIGN // Pure Yaw Rotation

MPU6050 Z-axis gyro integration + ultrasonic echo return maximizes normal incidence; robot spins in place ($\omega_1=\omega_2=\omega_3$) until $|\theta_{\text{err}}| < 0.2\text{ rad}$.

S3

STATE_APPROACH // Coupled Holonomic Glide

Simultaneous lateral ($V_x$) and forward ($V_z$) vectoring closes both lateral offset and range error while maintaining zero yaw error.

S4

STATE_SETTLE & LOCKED // PID Micro-Trim

Encoder feedback damps residual oscillation until range error $< 4\text{ mm}$ and heading error $< 0.5^\circ$ continuously for $0.6\text{ s}$.
